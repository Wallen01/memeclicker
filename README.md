# 迷因互動點擊器 (Meme Clicker) - 網頁規格書

> 這是一份「迷因互動點擊器」網頁專案規格書，完全排除程式碼，專注於功能、介面與互動邏輯的詳細定義。

## 一、 專案概述

本專案為一個單頁面互動式 Web 應用程式。使用者透過點擊與長按畫面中央的迷因圖片來進行互動，系統會記錄總點擊次數，並透過階段性的圖片切換與光影特效，提供豐富的「蓄力與釋放」視覺回饋。

---

## 二、 介面與版面配置 (UI Layout)

1. **整體佈局**
   - 採用全螢幕滿版、絕對置中的版面設計。

2. **核心圖片區 (Meme Image)**
   - 位於畫面正中央。
   - 尺寸限制：佔用整個畫面視覺範圍的全部。
   - 具備防反白、防拖曳屬性，避免使用者在長按或快速點擊時誤觸瀏覽器預設行為。

3. **點擊計數器 (Click Counter)**
   - 位於迷因圖片正下方。
   - 以醒目的字體顯示歷史總點擊次數。

4. **狀態長條與數據面板 (Status Bar & Info)**
   - 位於計數器下方。
   - 包含一條紅色的進度長條（平時隱藏，觸發時顯示）。
   - 即時顯示當下長按蓄力或冷卻倒數的「秒數」。

---

## 三、 美術素材需求 (Assets)

專案需準備同一系列、不同動作狀態的 4 張迷因圖片：

- **圖片 1 (待機狀態)**：未進行任何互動時的預設圖片。
- **圖片 2 (按下瞬間)**：使用者剛按下按鍵時的過渡動作圖片。
- **圖片 3 (蓄力狀態)**：使用者持續按住按鍵時的動作圖片。
- **圖片 4 (釋放狀態)**：使用者鬆開按鍵後的動作圖片。

---

## 四、 核心互動邏輯與視覺特效 (Interaction & Effects)

互動過程分為四個階段的狀態機，支援滑鼠點擊與行動裝置的觸控操作：

### 階段一：待機狀態 (Idle)
- **圖片顯示**：顯示「img1.png」。
- **特效狀態**：無任何光芒特效，紅色進度條隱藏，蓄力秒數為 0。

### 階段二：觸發按下 (Press Start)
- **觸發條件**：使用者按下圖片（滑鼠左鍵按下 或 手指觸控壓下）。
- **行為與轉換**：
  1. 總點擊次數計數器立即 +1。
  2. 圖片立即切換為「img2.png」。
  3. 系統停留 0.050 秒 (50毫秒) 後，自動進入「階段三：長按蓄力」。

### 階段三：長按蓄力 (Holding / Charging)
- **圖片顯示**：顯示「img3.png」。
- **時間紀錄**：系統開始精確計算並記錄使用者按住的總毫秒數 / 秒數，並同步顯示於畫面上。
- **視覺特效（漸強紅光）**：圖片上方出現「輻射狀的紅色光芒」。隨著按壓時間越長，紅色光芒的透明度會由完全透明逐漸轉為不透明（強度漸強），將整張圖片渲染成紅色。

### 階段四：鬆開釋放與冷卻倒數 (Release & Cooldown)
- **觸發條件**：使用者鬆開按鍵（滑鼠左鍵放開 或 手指離開螢幕）。
- **行為與轉換**：
  1. 圖片立即切換為「img4.png」。
  2. 畫面下方出現「紅色狀態長條」，初始長度為 100%。
  3. 系統將剛才累積的「長按總秒數」轉為「倒數計時」的額度，開始進行遞減倒數。
- **視覺特效（漸弱消退）**：
  - **紅色長條**：隨著倒數計時，長條寬度由 100% 逐漸縮減至 0%。
  - **輻射狀紅光**：疊加在圖片上的紅色光芒，也會跟隨倒數的進度，從釋放瞬間的最高亮度逐漸黯淡消退（漸弱）。
- **冷卻完成**：當秒數倒數至 0，紅條與紅光完全消失，系統自動重置回「階段一：待機狀態」，圖片切換回「圖片 1」，等待下一次點擊。

---

## 五、 資料儲存需求

- **總點擊次數持久化**：需具有持久化儲存機制（例如使用瀏覽器的 `localStorage` 本機儲存），確保使用者關閉網頁或重新整理後，點擊次數不會歸零，能延續先前的紀錄。
